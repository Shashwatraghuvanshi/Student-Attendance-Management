# Student Attendance Management System

A beginner-friendly attendance tracker made using basic HTML, CSS, and JavaScript.

## Features

- Add student names.
- Mark students as present or absent.
- View the total number of students, present students, and absent students.
- Calculate each student's attendance percentage from saved daily records.
- Save attendance records in the browser using `localStorage`.
- View previous attendance records.
- Simple responsive design.

## Project Files

```text
student-attendance-management/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone this repository.
2. Keep all four files in the same folder.
3. Open `index.html` in a web browser such as Google Chrome.
4. Add students, mark attendance, and click **Save Attendance**.

No installation or server is required.

## Technologies Used

- **HTML** – webpage structure
- **CSS** – page design and layout
- **JavaScript** – attendance functions and calculations
- **localStorage** – saving student and attendance data in the browser

## Important Notes

- Data is saved in the browser where the project is used. It is not automatically shared across devices or browsers.
- Clearing browser data may remove saved attendance records.
- The current version allows one saved attendance record per calendar day.
- Attendance percentage is calculated using the saved attendance records.
